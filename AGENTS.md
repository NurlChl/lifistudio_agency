# Lifi Studio — Agent Instructions

## Project Overview
Lifi Studio is a premium digital agency website and CMS platform owned by **Moh Nurul Cholil (NurlChl)**. Services offered:
- Web Development (WordPress, Next.js, Laravel, Vue)
- UI/UX Design
- Desain Grafis (Graphic Design)
- Automation Engineering (n8n, GHL, AI tools)

## Tech Stack
- **Framework:** Next.js 15+ (App Router) with TypeScript
- **Styling:** Tailwind CSS v4 with custom design tokens
- **Animation:** Framer Motion (primary) + GSAP (for scroll-triggered / heavy animations)
- **Database:** MongoDB via Mongoose
- **CMS:** Custom dashboard built inside the same Next.js app
- **Icons:** Lucide React (primary) + custom SVG icons where needed
- **Fonts:** Inter (body) + Playfair Display (headings) — or as defined in DESIGN.md
- **Authentication:** NextAuth.js / Auth.js for dashboard login
- **File Upload:** UploadThing or local multer for portfolio assets

## Design Principles
1. **Anti-AI Slop** — No glassmorphism, no generic SaaS cards with icons everywhere, no fake dashboards, no rainbow gradients, no "Insights" labels without content
2. **Premium Minimalism** — Inspired by only.digital: monochromatic + one accent, generous whitespace, strong typographic hierarchy
3. **Intentional Motion** — Framer Motion for subtle, purposeful animations that clarify state changes, not decorative fluff
4. **Content First** — Every element must earn its place. Real copy, real metrics when available, no filler
5. **Human Design** — Looks like it was crafted by a senior designer, not generated by AI

## Development Workflow
1. Always check DESIGN.md for token values before writing CSS
2. Use Tailwind custom classes matching design tokens (not raw arbitrary values)
3. Build mobile-first, then enhance for desktop
4. Verify visual output with browser tools after every major component
5. **Context7** — Untuk dokumentasi library terbaru, gunakan:
   - `npx ctx7 library <name> <query>` — cari library
   - `npx ctx7 docs <libraryId> <query>` — ambil dokumentasi
   - Atau cukup tulis "use context7" di prompt untuk dokumentasi otomatis
   - Setup OAuth: buka https://context7.com/oauth/device dan masukkan kode dari `npx ctx7 setup`
6. Commit messages: `type(scope): description` (e.g., `feat(home): add hero section with parallax`)

## Pages
### Public Site (`/`)
- `/` — Home (hero, services overview, featured portfolio, stats, CTA)
- `/portfolio` — Portfolio grid with filters (category, technology)
- `/portfolio/[slug]` — Single portfolio detail page
- `/services` — Services overview + individual service deep-dive
- `/about` — About Lifi Studio, team, journey
- `/blog` — Blog listing with categories
- `/blog/[slug]` — Single blog post
- `/contact` — Contact form with map/info

### Dashboard (`/dashboard`)
- Login page
- Overview / stats
- Portfolio management (CRUD)
- Blog management (CRUD with rich text editor)
- Contacts management (inbox, read, reply)
- Settings (profile, site info)

## CMS Features
- Authentication (email/password via Auth.js)
- Rich text editor for blog (TipTap or similar)
- Image upload with preview
- Portfolio: title, description, images, category, technologies, live URL, status
- Blog: title, content, excerpt, cover image, tags, publish status
- Contacts: name, email, message, read status, reply
- Server Actions for data mutations (no API routes for CRUD)
