# Lifi Studio — Brand Identity & Copy

## Brand Name
**Lifi Studio** — "Lifi" stands for **Life + Digital** (atau bisa juga **Layanan Digital**). Simple, modern, memorable.

## Tagline Options
1. *"One Studio. All Solutions."*
2. *"Digital yang Hidup."* (Digital that comes alive)
3. *"Desain. Kode. Otomasi."*
4. *"From Concept to Completion."*

## Brand Voice

### Personality
| Trait | How It Shows |
|-------|-------------|
| **Confident** | We state what we do clearly, no hedging |
| **Warm** | Indonesian hospitality, approachable tone |
| **Expert** | Show technical depth without jargon overload |
| **Honest** | No fake metrics, no overpromising |

### Tone by Channel
| Page | Tone |
|------|------|
| Home | Bold, aspirational, confident |
| Portfolio | Proud, detailed, results-oriented |
| Services | Expert, educational, clear |
| About | Personal, authentic, warm |
| Blog | Helpful, insightful, generous |
| Contact | Friendly, responsive, welcoming |

## Key Messages

### Value Proposition (Home Hero)
> *"Kamu butuh website? Butuh desain? Butuh sistem otomatis? Cukup satu tempat: **Lifi Studio.** "*

### Problem We Solve
> *"Biasanya orang hire web dev sendiri, desainer sendiri, marketing sendiri — ribet, mahal, nggak nyambung satu sama lain. Lifi Studio kasih **semuanya dalam satu tim yang terintegrasi.** Web development, UI/UX design, desain grafis, dan automation engineering — semua dikerjain bareng, hasilnya maksimal."*

### For Each Service

**Web Development**
> *"Dari WordPress company profile sampai Next.js marketplace — kami bangun website yang cepat, aman, dan mudah dikelola."*

**UI/UX Design**
> *"Bukan cuma 'cantik'. Setiap pixel ada tujuannya — biar pengunjung betah dan konversi naik."*

**Graphic Design**
> *"Logo, banner, social media visuals — identitas visual yang bikin brand kamu langsung dikenal."*

**Automation Engineering**
> *"Pakai n8n, GHL, dan AI tools — otomatiskan workflow kamu. Kirim invoice otomatis, follow-up pelanggan, sinkron data tanpa ribet."*

## Social Proof Strategy
- Show real portfolio items with real results
- Client count: "30+ satisfied clients"
- Project count: "100+ projects delivered"
- Experience: "4+ years in the industry"
- Include recognizable tech logos (WordPress, Next.js, Laravel, Vue, n8n)

## CTA Phrases
- "Mulai Proyek" / "Start Project"
- "Diskusikan Ide Kamu"
- "Lihat Portfolio"
- "Hubungi Kami"
- "Dapatkan Konsultasi Gratis"

## Bahasa Mix
Since Lifi Studio is Indonesia-based:
- **Home/Services/About:** Mix Indonesian + English (sophisticated)
- **Portfolio:** English (universal)
- **Blog:** Indonesian (local audience)
- **Dashboard UI:** English (developer-friendly)
- **Contact form:** Indonesian + English options

## Color Psychology
- **Terracotta/Clay accent** — warmth, earthiness, confidence (beda dari agensi rata-rata yang pake biru atau hijau)
- **Warm neutrals** — sophisticated, premium, approachable
- **Gold touches** — premium feel, excellence
