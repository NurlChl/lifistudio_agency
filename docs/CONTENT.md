## Service Pages

### Web Development
**What we build:**
- Company Profile / Brand Website
- E-commerce (WordPress + WooCommerce / custom)
- Web Application (Next.js, Laravel, Vue)
- Landing Pages & Microsites
- CMS Integration

**Tech:** WordPress, Next.js, Laravel, Vue.js, Tailwind, MongoDB, MySQL

### UI/UX Design
**Our process:**
1. **Discovery** — Understand goals, users, competition
2. **Research** — User interviews, analytics review
3. **Wireframe** — Layout & flow without visual noise
4. **Prototype** — Interactive mockup in Figma
5. **Visual Design** — Full UI dengan design system
6. **Handoff** — Developer-ready specs + assets

**Tools:** Figma, Adobe Creative Suite, Framer

### Graphic Design
**What we create:**
- Brand Identity (logo, color, typography system)
- Social Media Templates
- Marketing Collateral (brosur, banner, poster)
- Presentation Design
- Icon & Illustration

### Automation Engineering
**What we automate:**
- **CRM & Lead Management** — GHL, HubSpot integrations
- **Workflow Automation** — n8n workflows
- **AI Integration** — ChatGPT, custom AI tools
- **Email Marketing** — Automated sequences
- **Data Sync** — Between platforms (e.g., Shopify → Google Sheets → GHL)
- **Reporting** — Automated report generation
